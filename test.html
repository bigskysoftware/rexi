Verb helpers

get(url).raw() returns the raw Response

get(url).json() parses JSON body

get(url).text() returns text body

get(url).html() returns a DocumentFragment parsed via <template>

post(url, object) sends JSON with Content-Type application/json

put / patch / del use the right HTTP methods

Body normalization

post(url, HTMLFormElement) sends FormData with form fields

post(url, singleInputElement) sends FormData with a single entry

post(url, iterableOfElements) collects each element's name/value

post(url, FormData) passes the FormData through unchanged

post(url, null) sends no body

post(url, string) sends the string as the raw body

post(url, Blob) sends the blob as the raw body

post(url, URLSearchParams) sends it as the raw body (urlencoded form)

post(url, fileInput) appends File objects, not filename strings

post(url, checkbox) only includes checked ones

post(url, selectMultiple) includes every selected option

Raw body in query mode

get(url, string) parses the string as pre-encoded query params

get(url, URLSearchParams) serializes via the URLSearchParams

Query-string encoding (GET / HEAD / DEL)

get(url, {a: 1, b: "x"}) URL-encodes as query string

get(url, {tag: [1,2,3]}) repeats the key for array values

get preserves existing query params in the URL

del(url, body) URL-encodes body by default

opts.include

include: selector merges extra form fields

include: array of selectors merges all

include: with a JSON body promotes the request to form mode

opts.send override

send: "body" forces DELETE to send as body

send: "query" forces POST to URL-encode

Error handling

Non-2xx throws Error with .status and .response

Thrown error.response.text() gives the error body

Abort and timeout

.abort() cancels an in-flight request with AbortError

{timeout: N} aborts after N ms with AbortError

external opts.signal.abort() also cancels the request

Lifecycle events

rexi:before fires with detail.cfg = {url, init}

rexi:before can mutate init (e.g. inject Authorization header)

rexi:before preventDefault() cancels the request with AbortError

rexi:after fires with detail.response on success

rexi:after fires even on non-2xx (then rexi still throws)

Globals and namespace

rexi namespace exposes the six verbs (del, not delete)

Globals get/head/post/put/patch/del attached to window
